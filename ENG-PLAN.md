## 技术栈

- **后端**: Node.js 20+ / Fastify 5 / TypeScript (strict)
- **数据库**: PostgreSQL 16 (JSONB 元数据)
- **部署**: 腾讯云/阿里云轻量应用服务器 2核4G, Ubuntu 24.04, Docker Compose, Caddy/Nginx 反代 HTTPS
- **搜索**: 入库时 jieba 预分词 → search_text 列 + to_tsvector('simple') + GIN 索引
- **定时任务**: node-cron(二期自动化图源时启用;MVP 内容为人工触发的精选导入)
- **校验**: zod (env 配置 + manifest/上游响应)
- **对象存储**: 腾讯云 COS(私有读 + 签名直链分发)
- **测试**: vitest (unit) + 集成测试 + CI

## 数据库 Schema

```sql
-- 壁纸元数据 (JSONB 缓存表)
CREATE TABLE wallpapers (
  id            BIGSERIAL PRIMARY KEY,
  source        TEXT NOT NULL,              -- 'wikimedia'
  source_id     TEXT NOT NULL,              -- 上游唯一 ID
  title         TEXT,
  url           TEXT NOT NULL,              -- 原图 URL
  thumb_url     TEXT NOT NULL,              -- 缩略图 URL
  license       TEXT NOT NULL,
  license_url   TEXT,
  creator       TEXT,
  creator_url   TEXT,
  width         INT,
  height        INT,
  tags          TEXT[],                    -- 标签数组
  search_text   TEXT,                       -- jieba 预分词结果
  category      TEXT,                       -- 中文分类
  status        TEXT DEFAULT 'active',      -- active/blocked(内容安全)
  created_at    TIMESTAMPTZ DEFAULT now(),
  updated_at    TIMESTAMPTZ DEFAULT now(),
  UNIQUE (source, source_id)
);
CREATE INDEX idx_wallpapers_category_created ON wallpapers (category, created_at DESC);
CREATE INDEX idx_wallpapers_search ON wallpapers USING GIN (to_tsvector('simple', search_text));
CREATE INDEX idx_wallpapers_tags ON wallpapers USING GIN (tags);

-- 收藏
CREATE TABLE favorites (
  user_id    TEXT NOT NULL,               -- openid (哈希后存储, PIPL)
  wallpaper_id BIGINT NOT NULL REFERENCES wallpapers(id),
  created_at TIMESTAMPTZ DEFAULT now(),
  PRIMARY KEY (user_id, wallpaper_id)
);

-- 激励视频解锁记录
CREATE TABLE ad_unlocks (
  id          BIGSERIAL PRIMARY KEY,
  user_id     TEXT NOT NULL,              -- openid 哈希
  wallpaper_id BIGINT NOT NULL REFERENCES wallpapers(id),
  unlock_key  TEXT NOT NULL,              -- 服务端回调凭证(防重放)
  created_at  TIMESTAMPTZ DEFAULT now(),
  UNIQUE (user_id, wallpaper_id)
);

-- 举报
CREATE TABLE reports (
  id           BIGSERIAL PRIMARY KEY,
  user_id      TEXT NOT NULL,
  wallpaper_id BIGINT NOT NULL REFERENCES wallpapers(id),
  reason       TEXT,
  created_at   TIMESTAMPTZ DEFAULT now(),
  UNIQUE (user_id, wallpaper_id)         -- 每用户每图最多一次
);

-- 埋点事件
CREATE TABLE events (
  id           BIGSERIAL PRIMARY KEY,
  event_name   TEXT NOT NULL,             -- search_exposed/search_click/preview_click/download_click/download_success
  event_id     TEXT NOT NULL,             -- 客户端生成 UUID, 去重
  user_id      TEXT,
  wallpaper_id BIGINT,
  extra        JSONB,
  created_at   TIMESTAMPTZ DEFAULT now(),
  UNIQUE (event_id)                       -- 幂等去重
);
CREATE INDEX idx_events_name_created ON events (event_name, created_at);
```

## 错误映射 (Section 2 审查输出)

| 场景 | 异常 | 处理 | 用户看到 |
|------|------|------|----------|
| COS 上传/签名失败 | StorageError | 导入重试 + 告警;读侧签名重试 | 图片暂不可用(重试) |
| manifest 解析错误 | ParseError | 跳过该条 + 告警 | 该条缺失(其余正常) |
| 上游响应畸形 | ZodValidationError | 拒绝该条 + 日志 + 告警 | 无影响(跳过坏数据) |
| DB 连接失败 | ConnectionError | 503 + 告警 | "服务暂时不可用" |
| 签名 URL 过期 | ExpiredUrlError | 前端重新请求详情刷新 URL | 重试提示 |
| 内容安全检测失败 | SecurityCheckError | 拒绝入库 + 告警 | 无影响(不展示) |

## 测试计划 (Section 3 审查输出)

- **Unit**: zod schema 校验(缺失/类型错)、Source 映射(正常/空/畸形)、错误映射、限流中间件、埋点去重
- **Integration**: CuratedImport manifest 全流程、IngestionService(内容安全 mock)、导入幂等性(中断重跑无重复)、COS 上传/签名、SearchService(中文分词/同义词/拼音)、激励视频防绕过(伪造 openid/重复解锁/回调重放)
- **E2E**: 打开→找到→保存全流程、解锁→下载高清、漏斗事件落库
- **CI**: GitHub Actions — lint + typecheck + unit + integration

## 性能决策 (Section 4 审查输出)

- 信息流: keyset 分页 (created_at, id) — 避免深 offset
- 搜索: 入库预分词 + FTS GIN 索引 — 无运行时 LIKE
- 缓存: 不加 Redis — 100-300 张元数据 Postgres 够用
- 图片: **COS 签名直链**(2026-08-10 二次修正)— 精选 CC0 语料转存国内 COS,私有读 + 短期签名 URL;大陆天然可达、防爬、免后端带宽

## 安全决策

- API key / env 仅存后端, zod 校验 env
- **鉴权(Outside Voice 修正)**: 微信 code2Session → openid → **HMAC 哈希存储**(非裸哈希,防字典攻击)→ 签发短时效 token(JWT/自签,含过期/刷新),接口统一鉴权
- openid 用 keyed HMAC 存储 (PIPL)
- **激励视频修正(Outside Voice)**: MVP 阶段流量主未开通,高清解锁改为**全免费 + 后端校验接口**(记录 openid+壁纸,防脚本刷),真实广告服务端回调验证二期接入时再调研 WeChat 回调能力
- 举报限流 (每用户每图一次)
- 内容安全检测在入库时 (imgSecCheck)
